Context, quota, cache and cost at a glance

Every segment is one metric with its own color thresholds. Turn any of them off.

████████░░ 71% (142K/200K)

Context health

A ten-character bar with absolute tokens, not just a percentage. Formats as K or M, so a 1M window reads the same way.

█████████░ 94% (4h37m/5h)

Quota windows

The 5-hour and 7-day limits with time to reset, taken from the rate_limits field Claude Code already sends.

Cache:99% | Wait:6%

Cache and wait

How much of the last call hit the prompt cache, and what share of the session was spent waiting on the API.

Cost:$0.03/m | $185.4

Cost velocity

Dollars per minute next to the session total. Fifteen thresholds decide when each color changes.

Past 85%, it gets out of the way

When context crosses the danger threshold, Howl collapses to two dense lines: tokens left, time left, and the numbers that still matter. Use the controls above the HUD to switch presets and modes, or click a preset here.

Install from Claude Code

Howl ships as a Claude Code plugin from its own marketplace. Setup downloads the binary for your OS and writes the status line setting for you.

/plugin marketplace add ai-screams/howl
/plugin install howl@ai-screams-howl
/howl:setup
